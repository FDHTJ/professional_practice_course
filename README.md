This repository contains the code for the Professional Practice course (Fall Semester 2025). It includes implementations for Pigeon IRIR comparison and retrieval, as well as an AI assistant built with PyTorch.

Due to file size limitations, some trained models and raw data are not hosted in this repository. They can be accessed via [Models and Raw data](https://pan.quark.cn/s/5b395b424cc0?pwd=hbML).

For detailed descriptions of our implementation and experimental results, please refer to the [Report](report.pdf).

If you have any questions, feel free to contact us at dehangfu@cufe.edu.cn.
